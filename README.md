## 🚀 Local Development

```bash
# 1. Clone repository
git clone https://github.com/SithumManusha/portfolio.git
cd portfolio

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. Compile production build
npm run build
```
